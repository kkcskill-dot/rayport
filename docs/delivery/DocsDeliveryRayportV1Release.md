# Rayport 1.0.0 구현·검증 기록

작성일: 2026-11-08. 첫 단일 노드 구현 릴리스. 고객 운영계 인수 완료를 뜻하지 않는다.

## 완료 범위

Rust 네 crate, React 실제 HTTP 클라이언트, 인증·역할·점포 권한, 도구 초안·편집·검증·게시·폐기, OpenAPI/MCP 메타데이터 export, SQL 템플릿 관측자료 반입·후보 생성, 마트 완전 스냅샷 반입·조회, 질문 매칭·생성 요청·원질문 재조회·해결 확인, 실행 예산·종료 확인·감사, 파일 저장·업그레이드·롤백 도구를 구현했다.

## 검증 환경과 결과

공식 Node 24.22.2 LTS, Rust 1.99.1을 사용자 전용 경로에 설치하고 배포 체크섬을 확인했다. Mac SDK는 기존 CommandLineTools의 26.5를 빌드 환경에만 지정했다. 전역 profile·SDK 설정은 바꾸지 않았다. 의존성은 Cargo.lock/package-lock.json으로 고정했다.

통합 실행에서 도메인 27개, 응용 27개, 저장 14개, HTTP 24개로 Rust 92개, 프론트 29개, 설치 10개 **총 131개 테스트가 통과**했다. Clippy 경고 0건, TypeScript·Vite production build, 구조 검사 76파일/48상대 import도 통과했다. 테스트 수는 기능 범위나 운영계 검증을 대신하지 않는다.

검증은 단위 함수·임시 파일·in-process Router·JSDOM을 사용했다. 서버 listener, 로컬 DB, Docker/Testcontainers, 운영 DB 접속은 수행하지 않았다. 실제 브라우저 접근성/키보드·TLS 역방향 프록시·Linux·고객 APIC·DB 실취소·부하·백업 복구 리허설은 미검증이다.

## 의도적으로 한정한 범위

- 한 설치당 하나의 tenant, 단일 writer. 파일 저장소는 로컬 파일시스템과 64MiB snapshot 상한, 마트당 20,000행·현재 마트 총 100,000행·최근 2버전이다. 매 요청의 파일 쓰기 비용 때문에 고동시성·대용량 제품 구성을 뜻하지 않는다.
- 질문은 등록 검색어 기반이다. 임의 자연어/원인 추론/범용 SQL 생성은 제공하지 않는다.
- SQL 리터럴·주석·비지원 구문은 반입을 거절한다. 안전한 바인드 템플릿을 DBA가 제공해야 한다. AWR/ASH JSON 관측 반입을 Oracle 자동 수집·원문 HTML/PDF 분석과 혼동하지 않는다.
- 자동 마트 갱신 스케줄러·증분 CDC·외부 SSO·MCP 전송 서버·APIC 네이티브 자동 등록은 미구현이다. 현재 기능은 수동 반입과 생성된 메타데이터·실행 계약이다.
- 실제 APIC 소스와 원격 환경이 없어 네이티브 통합·실취소·부하 인수를 수행하지 못했다. 기본 원천 실행 비활성은 유지한다.

## 마감 기록

최종 통합 회귀·Clippy·타입 검사·production build·구조 검사·설치 회귀를 통과했다. 이 Mac의 native 대상은 `aarch64-apple-darwin`이다. 배포 파일은 `dist/rayport-1.0.0-aarch64-apple-darwin.tar.gz`와 같은 이름의 `.sha256`으로 생성했다. Linux 패키지는 Linux runner에서 별도로 빌드해야 하며 이 Mac 산출물을 Linux 실행 파일로 사용하지 않는다.

실제 archive의 SHA256을 확인하고 임시 디렉터리에 설치했다. 설치기가 전체 파일 checksum·플랫폼을 검사한 후, 포함된 바이너리의 `--version`이 `rayport-server 1.0.0`을 반환했다. 이어서 `init`과 `check`가 성공했고 설정·초기 토큰 파일 권한 600 및 production 웹 파일을 확인했다. 토큰 내용은 출력하지 않았으며 임시 설치는 검사 후 제거했다. 서비스 listener와 외부 연결은 열지 않았다. 이 설치 점검은 위 131개 회귀 테스트 수에 포함하지 않는다.
